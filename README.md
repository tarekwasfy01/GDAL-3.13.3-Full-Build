## About GDAL

**GDAL – Geospatial Data Abstraction Library** is an open-source library and toolkit for reading, writing, converting, processing, and analyzing raster and vector geospatial data.

GDAL is widely used throughout the GIS and remote-sensing ecosystem and forms part of the underlying geospatial infrastructure of many desktop, server, and scientific applications.
